# STOCKLINE

STOCKLINE is a JSE stock tracker for South African equities. It uses FastAPI, SQLAlchemy, and a plain HTML/JavaScript frontend.

## Commands

- Install: `pip install -r requirements.txt`
- Run: `uvicorn app.main:app --reload`
- Test: `pytest`

## Rules

- Read the GitHub issue and its acceptance criteria before coding.
- Do not change the acceptance criteria.
- Stay inside the files named by the issue.
- Write tests for every behaviour.
- Commit after each meaningful step.
- Do not close issues.
- Do not add dependencies without asking.
